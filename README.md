# Уютный Климат 56 — сайт

Статический сайт (HTML + CSS + JS), без сборки.

## Страницы
- `index.html` — главная (направления, калькулятор, акции б/у, фото работ, FAQ, форма)
- `konditsionery.html` — кондиционеры (услуги, цены, калькулятор, б/у)
- `ventilyatsiya.html` — вентиляция
- `otoplenie.html`, `vodosnabzhenie.html`, `elektrika.html`, `santehnika.html`
- `aktsii.html` — акционные товары с фильтром по направлениям. Скидка «−N%» считается сама из старой (`<s>`) и новой (`<b>`) цены. Направление товара задаётся атрибутом `data-cat`.

Шапка, меню, подвал и окно заявки собираются скриптом `js/main.js` — правятся в одном месте для всех страниц.

## Что заменить на настоящее
1. **Контакты** — объект `SITE` в начале `js/main.js` (телефон, WhatsApp, Telegram, адрес, часы, почта).
2. **Цены калькулятора** — объект `CALC_PRICES` в `js/calc.js`.
3. **Цены услуг** — блоки `price-row` на страницах направлений.
4. **Акционные кондиционеры и акции** — карточки `product` в `index.html` (блок «Акции»).
5. **Товары на вкладках** — блок «Каталог» (`id="catalog"`) на каждой странице направления. Фото товаров кладите в `img/products/` (`ac-1.jpg`…, `heat-1.jpg`…, `vent-`, `water-`, `el-`, `san-`).
6. **Цвета** — переменные `--warm` (красный) и `--cold` (голубой) в начале `css/style.css`, из них собирается фирменный градиент.
5. **Фото работ** — положите файлы в `img/works/` (`1.jpg`…`5.jpg` для главной, `ac-1.jpg`…`ac-5.jpg` для кондиционеров). Пока фото нет, показывается заглушка.
6. **Приём заявок** — функция `sendLead()` в `js/main.js`. Сейчас заявка только пишется в консоль браузера; нужно подключить Telegram-бота, почту или CRM.

После правок JS меняйте `?v=2` в ссылках на скрипты, чтобы браузеры не держали старую версию.

## Публикация
- **GitHub Pages** (открывается в РФ): https://jopkohopko-blip.github.io/klimat56/ — обновляется сам после `git push` в ветку `main`.
- Cloudflare Pages: `.\deploy.ps1` → https://klimat56.pages.dev (в РФ может не открываться).

Пока сайт черновой, на всех страницах стоит `<meta name="robots" content="noindex, nofollow">`. Перед запуском его нужно убрать.
